# Aura — Zero-Knowledge Vault & Secure Workspace

Полноценное веб-приложение для безопасного управления личными данными, заметками и секретами (API-ключами, паролями) с бескомпромиссной архитектурой **Zero-Knowledge**, современным кибер-минималистичным интерфейсом, клиентским шифрованием **AES-256-GCM**, серверным хешированием **Argon2id** и облачной базой данных **Turso (libSQL)**.

---

## 🛡️ Архитектура безопасности Zero-Knowledge

Главный принцип системы — **серверу и базе данных нельзя доверять по умолчанию**. Даже при полной компрометации сервера, перехвате сетевого трафика или утечке базы данных конфиденциальная информация пользователей остаётся в полной безопасности.

### 1. Симметричное клиентское шифрование (AES-256-GCM)
* **Web Crypto API:** Все пароли, API-ключи и заметки шифруются прямо в браузере через нативный криптографический интерфейс `window.crypto.subtle`.
* **Вектор инициализации (IV):** Для каждой записи генерируется случайный криптографический 12-байтный вектор инициализации (`crypto.getRandomValues`).
* **Только шифротекст:** Сервер и база данных видят исключительно зашифрованные блоки Base64 и IV. Исходный открытый текст (plaintext) никогда не покидает оперативную память клиентской вкладки.

### 2. Клиентская деривация ключей (PBKDF2)
* Из мастер-пароля и индивидуальной соли в браузере вырабатывается 512 бит энтропии (100 000 итераций `PBKDF2-HMAC-SHA256`):
  * **Первые 256 бит (`authKey`):** хешируются через SHA-256 и в виде `auth_key_hash` передаются серверу для аутентификации.
  * **Вторые 256 бит (`encryptionKey`):** импортируются как ключ **AES-GCM (256 бит)** и хранятся **строго в оперативной памяти (RAM)** браузера.
* **Мастер-пароль никогда не передается по сети.**

### 3. Защита мастер-пароля от GPU-перебора (Argon2id)
* На стороне сервера `auth_key_hash` повторно хешируется алгоритмом **Argon2id** (`argon2-cffi`):
  * Память (`memory_cost`): **64 МБ** на каждый расчет;
  * Итерации (`time_cost`): **2**;
  * Параллелизм (`parallelism`): **1**;
  * Тип: **Argon2id** (гибрид Argon2d и Argon2i, наивысшая защита от атак по побочным каналам и перебора на GPU/ASIC фермах).

### 4. Защита сессий от XSS (HttpOnly Secure SameSite Cookies)
* Полный отказ от хранения токенов в `localStorage`.
* Токен сессии передается исключительно в заголовке `Set-Cookie` с параметрами:
  * `HttpOnly = True` — кука недоступна для чтения через JavaScript (неуязвима для XSS);
  * `SameSite = Lax` — защита от атак межсайтовой подделки запросов (CSRF);
  * `Secure = True` — передача исключительно по зашифрованному протоколу HTTPS в production.

### 5. Непредсказуемые идентификаторы (UUIDv4)
* Отказ от уязвимых инкрементных числовых ID (`#1`, `#2` и т.д.) в пользу стандарта **UUIDv4** (`str(uuid.uuid4())`).
* Исключена возможность перечисления (enumeration) или перебора идентификаторов пользователей и записей.

### 6. Защита от Brute-Force (Rate Limiting)
* Скользящий алгоритм ограничения попыток по IP-адресу на эндпоинтах `/api/login`, `/api/register` и `/api/change-password` (максимум 5 попыток в минуту).
* При превышении возвращается код `HTTP 429 Too Many Requests` с заголовком `Retry-After`.
* Защита от перебора логинов: эндпоинт получения соли `/api/auth/salt` возвращает детерминированную псевдосоль для несуществующих логинов, не позволяя злоумышленнику определить наличие аккаунта в системе.

## ⚡ Функции интерфейса безопасности

* **Встроенный генератор криптостойких паролей:**
  * Настраиваемая длина (от 8 до 64 символов) и выбор наборов символов (A-Z, a-z, 0-9, спецсимволы).
  * Генерация на базе криптографически стойкого генератора псевдослучайных чисел `crypto.getRandomValues`.
* **Автоматическая очистка буфера обмена через 60 секунд:**
  * При копировании пароля, API-ключа или UUID буфер обмена операционной системы автоматически стирается ровно через 1 минуту с выводом уведомления пользователю.
* **Автоблокировка хранилища (Inactivity Auto-Lock):**
  * При отсутствии активности пользователя в течение 5 минут (или по клику на кнопку «Заблокировать») ключ шифрования мгновенно удаляется из оперативной памяти, а экран блокируется до повторного ввода мастер-пароля.
* **Бесшовная перешифровка заметок:**
  * При смене мастер-пароля все существующие записи пользователя автоматически перешифровываются новым ключом прямо в памяти браузера и обновляются в БД без потери доступа.

## 🗄️ База данных: Turso Cloud + SQLite Local Fallback

* **Turso (libSQL):** Распределенная облачная база данных на базе SQLite Edge. Обеспечивает персистентное сохранение данных независимо от жизненного цикла контейнера хостинга.
* **Автоматический Fallback:** При любых сбоях сети или недоступности облака сервер не падает, а мгновенно переключается на локальный файл `database.db`.

---

## 🛠️ Стек технологий

* **Backend:** Python 3.11+, FastAPI, Uvicorn, Argon2-cffi, LibSQL Client, Pydantic v2.
* **Frontend:** Vanilla JavaScript (ES6+), Web Crypto API (`SubtleCrypto`), HTML5 Semantic, CSS3 Glassmorphism (без сторонних тяжелых фреймворков и npm-зависимостей).
* **Cloud & Deploy:** Render (PaaS Web Service), Turso Cloud DB (Edge SQLite).

## 🚀 Быстрый старт локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:uioree/scripting.git
   cd scripting
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # Linux / macOS:
   source .venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   python app.py
   ```

После запуска приложение доступно по адресу `http://127.0.0.1:8000`.
