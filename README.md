# Aura — Secure Workspace & Vault

Полноценное веб-приложение для безопасного управления личными данными, заметками и секретами (API-ключами, паролями) с современным кибер-минималистичным интерфейсом на базе **FastAPI** и **SQLite**.

## Возможности

- **Личный сейф записей (Aura Vault):** создание, фильтрация по категориям (заметки, пароли, API-ключи, секреты), быстрый поиск, копирование в буфер и маскирование конфиденциальных данных.
- **Строгая изоляция данных:** каждый пользователь имеет доступ исключительно к своим записям. Запросы в БД защищены параметризацией и проверкой прав владельца.
- **Надежная безопасность:**
  - Пароли хешируются с использованием `PBKDF2-HMAC-SHA256` (100 000 итераций) и индивидуальной криптографической соли.
  - Сессии аутентифицируются через защищенные `Bearer` токены с валидацией срока действия и возможностью серверного отзыва при выходе.
  - База данных `database.db` изолирована и недоступна для прямого скачивания через браузер, а также исключена из git-репозитория.
- **Управление профилем:** смена пароля с верификацией текущего пароля и проверкой сложности.
- **Персистентность авторизации:** сохранение сессии при перезагрузке страницы.

## Стек технологий

- **Backend:** Python 3.10+, FastAPI, SQLite3, Pydantic v2, Uvicorn
- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Glassmorphism, CSS Custom Properties, адаптивная сетка без тяжелых внешних библиотек)

## Быстрый старт

1. Склонируйте репозиторий:
   ```bash
   git clone git@github.com:uioree/scripting.git
   cd scripting
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # Linux / macOS:
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:
   ```bash
   python app.py
   ```

После запуска приложение будет доступно по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000). (Интерактивная API-документация Swagger доступна только при `DEBUG=1`).
