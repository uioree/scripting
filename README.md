# Aura Vault

Личное Zero-Knowledge хранилище паролей, API-ключей и заметок. Главная идея — сервер и база данных физически не могут прочитать то, что сохранил пользователь. Всё шифруется прямо в браузере до отправки по сети.

## Как устроена безопасность

В большинстве сервисов данные шифруются на сервере, а значит разработчики, хостинг или злоумышленник с доступом к базе могут прочитать всё содержимое. Здесь реализована архитектура с нулевым доверием (Zero-Knowledge):

- **Шифрование на клиенте (AES-256-GCM):** Секреты шифруются прямо в браузере через нативный Web Crypto API (`crypto.subtle`). На сервер отправляется только зашифрованный шифротекст и случайный 12-байтный IV. Ключ шифрования живет исключительно в оперативной памяти вкладки и никогда не уходит в сеть.
- **Мастер-пароль не покидает браузер:** Через PBKDF2 (100 000 итераций SHA-256) из пароля и индивидуальной соли выводятся два ключа: ключ шифрования (остается в RAM) и ключ аутентификации (в виде хеша отправляется на сервер для подтверждения входа).
- **Хеширование через Argon2id:** На бэкенде ключ проверяется с помощью современного алгоритма Argon2id с расходом 64 МБ оперативной памяти на попытку, что исключает перебор паролей на видеокартах (GPU).
- **Сессии в HttpOnly куках:** Никаких токенов в `localStorage`. Сессионный токен живет в `HttpOnly; SameSite=Lax; Secure` cookie, поэтому его физически нельзя украсть через XSS-скрипты.
- **Случайные UUIDv4 вместо ID:** Отказ от порядковых номеров записей (#1, #2). У каждого объекта свой криптографически случайный идентификатор, исключающий перебор.
- **Защита от брутфорса:** Лимит 5 попыток в минуту на логин и смену пароля (с отдачей HTTP 429). При запросе соли для неизвестного логина выдается правдоподобная псевдо-соль, чтобы нельзя было сканировать существующие логины в системе.

## Возможности

- Разделение записей по категориям (заметки, пароли, API-ключи, секреты), быстрый поиск и фильтрация.
- Скрытие и просмотр чувствительных полей по клику на иконку глаза.
- Встроенный генератор криптостойких паролей (от 8 до 64 знаков, выбор наборов символов на базе `crypto.getRandomValues`).
- Быстрое копирование с автоочисткой: скопированный в буфер обмена пароль или секрет автоматически стирается из памяти системы ровно через 60 секунд.
- Автоблокировка: если не трогать вкладку 5 минут, ключ шифрования стирается из оперативной памяти, а экран блокируется до повторного ввода мастер-пароля.
- Бесшовная смена мастер-пароля: при изменении пароля все текущие записи в памяти перешифровываются новым ключом и обновляются в базе без потери доступа.

## База данных

- В продакшене данные сохраняются в распределенной облачной SQLite — **Turso** (libSQL).
- Сделан авто-фоллбэк: если база недоступна или есть сетевой сбой, сервер не падает, а мягко переключается на локальный `database.db`.

## Стек технологий

- **Backend:** Python 3.11, FastAPI, Uvicorn, argon2-cffi, libsql-client, pydantic v2.
- **Frontend:** Чистый HTML5, CSS3 (темная тема со стеклянным эффектом) и Vanilla JS (без внешних фреймворков и лишних npm-пакетов).

## Локальный запуск

```bash
# Клонировать репозиторий
git clone git@github.com:uioree/scripting.git
cd scripting

# Создать и активировать виртуальное окружение
python -m venv .venv
.venv\Scripts\Activate.ps1  # Windows PowerShell
# source .venv/bin/activate # Linux / macOS

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
python app.py
```

После старта приложение доступно по адресу `http://127.0.0.1:8000`.
