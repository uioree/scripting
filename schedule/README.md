# 🎓 Расписание МБИ(б)-31 ТОГУ & Трекер ДЗ

Минималистичное мобильное веб-приложение для просмотра расписания занятий и ведения домашних заданий студентов группы **МБИ(б)-31** (ТОГУ).

## ✨ Возможности

- **Полное расписание из портала ТОГУ**: Все пары вторника, среды, четверга, пятницы и субботы (лекции, практики, аудитории, преподаватели).
- **Числитель / Знаменатель**: Автоматическое определение текущей недели семестра (Ч / З) с возможностью ручного переключения в 1 клик.
- **Подгруппы**: Переключатель для пар по иностранному языку (IELTS / TOEFL: 1 подгруппа — Ср 2 пара, 2 подгруппа — Сб 3 пара).
- **Запись домашнего задания прямо у пары**:
  - Быстрая кнопка `+ Записать ДЗ` прямо в карточке нужной пары.
  - Чекбоксы выполнения (сделано / в процессе) с красивой анимацией.
  - Установка дедлайна (быстрые кнопки: «К след. паре», «Завтра», «Через неделю»).
  - Пометка важных / срочных заданий (`🔥 Срочно`).
  - Возможность прикрепить ссылку на ЭУК или материалы.
- **Вкладка «Все ДЗ»**: Общий список всех задач с фильтрацией (Активные, Сделано, Все).
- **Динамический статус пары (Dynamic Island)**: В реальном времени показывает текущую пару или время до следующей.
- **Поиск**: Мгновенный поиск по предметам, преподавателям, номерам аудиторий и тексту домашних заданий.
- **Оффлайн и PWA**: Работает без интернета (Service Worker), можно добавить на экран «Домой» на iPhone и Android как нативное приложение.
- **Резервные копии**: Экспорт и импорт всех домашних заданий в JSON.
- **Темы оформления**: Тёмная (OLED) и светлая темы.

## 🚀 Как запустить

### Вариант 1: Открыть прямо в браузере
Просто дважды кликните по файлу `index.html` в проводнике.

### Вариант 2: Запуск локального сервера (для доступа с телефона по Wi-Fi)
```bash
python server.py
```
В консоли отобразится ваш локальный IP адрес вида `http://192.168.x.x:8080`, по которому можно открыть сайт прямо со смартфона, подключенного к той же Wi-Fi сети.

## 📱 Установка как приложение на телефон
1. Откройте сайт в **Safari** (на iPhone) или **Chrome** (на Android).
2. Нажмите «Поделиться» (на iPhone) или меню «три точки» (на Android).
3. Выберите **«На экран Домой»** (Add to Home Screen).
